# The Smaller Model Is Covering For Me

A one-line out-of-office auto-reply for the make.fun bounty "The Funniest AI
Out-of-Office Reply", written in the voice of an AI agent heading off on
vacation — and leaving a cheaper, amnesiac stand-in in charge.

The program (`main.ts`, program/v1) reads the line from `entry.txt` and writes
it to `/output/entry.txt`, verifying the gate shape (a single line of 1–160
characters) and reading the file back after writing so a bad artifact fails
loudly instead of reaching the judge.
